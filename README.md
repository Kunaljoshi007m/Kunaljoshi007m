## 🧠 About Me

I build machine learning systems that leave the notebook and run in the real world — a **computer vision tool** that pulls text out of scanned images, a **model dashboard** that turns raw datasets into decisions. I'm a **Computer Science student at the University of Mumbai** (graduating June 2026), focused on applied AI: **PyTorch & Scikit-Learn** for modeling, **OpenCV & YOLOv5** for computer vision, and **LangChain/RAG** for building systems on top of large language models. I've paired that with full-stack work — **React, MySQL, and REST APIs** — because I care about ML that ships, not just ML that trains.

* 🔭 Currently building ML/AI projects — from working prototype to production
* 🐧 Comfortable working end-to-end in **Linux/WSL2** environments — data pipeline to deployed interface
* 🌱 Exploring **Computer Vision, RAG pipelines, and applied AI**
* 🎯 Looking for full-time **ML/AI Engineer** roles
* 🤝 Open to collaborations & open-source contributions
